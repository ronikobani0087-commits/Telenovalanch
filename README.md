# Google TV Launcher – Telenova Smart TV

واجهة لانشر بتصميم Google TV لشاشات Telenova Smart TV، مكتوبة بـ HTML وTailwind CSS وجافاسكربت، مع دعم التنقل بريموت التحكم (الأسهم / OK / Back).

## التشغيل
افتح index.html في أي متصفح.

## ملاحظات
- يحتاج اتصالاً بالإنترنت (Tailwind والخطوط والصور من CDN).
- أسماء التطبيقات وشعاراتها ملك لأصحابها.
